# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's security advisory feature for this repository. Do not include API keys, proprietary source code, or production data in a public issue.

Include the affected version, reproduction steps, expected impact, and any suggested mitigation.

## Sensitive data handling

AI enhancement is optional. When enabled, source code and limited dependency excerpts are sent to the configured provider. Local prompts and responses are stored in `.ai-cache/`; migration logs exclude API keys. Review provider terms and your authorization before processing private code.

The project does not collect telemetry and does not automatically modify Git history.
